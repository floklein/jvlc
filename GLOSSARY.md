# VLC Redesign

The vocabulary of the redesigned VLC desktop interface, as seen by the person watching or listening.

## Language

**Queue**:
The ordered list of media that plays now and next, advancing automatically.
_Avoid_: Playlist (for this meaning), play queue

**Playlist**:
A saved, named collection of media that the user curates; it plays only once added to the Queue.
_Avoid_: Queue

**Library pane**:
The narrow library list that opens beside the video, as opposed to the full-window library.
_Avoid_: Sidebar (for this meaning), compact library

**Mini player**:
The small video and controls in a corner of the full-window library while media plays.
_Avoid_: PiP, floating player

**Saved stream**:
A network address the user has opened or saved, listed in the library's Network section.
_Avoid_: Bookmark, favorite stream, URL history

**Cast**:
Sending what is playing to another device on the network, such as a Chromecast, instead of playing it in VLC.
_Avoid_: Render, renderer, stream (for this meaning)

**Pin**:
A user-added shortcut in the library sidebar to a folder, Playlist or stream.
_Avoid_: Favorite, bookmark

**Favorite**:
A heart the user puts on a media file or Playlist, gathered in a Favorites row on Home.
_Avoid_: Pin, star

**Show**:
A folder of episodes, wherever it lives on disk; its subfolders (such as seasons) belong to it.
_Avoid_: Series, season (for the whole), library show

**Preset**:
A named set of playback adjustments, such as languages, delays, subtitle look and filters, that the user attaches to Shows and that overrides the Profile only where it sets a value.
_Avoid_: Profile, configuration, settings preset

**Subtitle match**:
A remembered pairing of an episode with a subtitle file, so the subtitle loads every time that episode plays.
_Avoid_: Subtitle link, subtitle association

**Theme**:
The interface's color mode: Light, Dark, or System (follows the operating system's light/dark setting).
_Avoid_: Color scheme, Day/Night, skin

**Accent color**:
The single user-chosen color that marks interactive and active elements; the cone logo is not affected by it.
_Avoid_: Highlight color, theme color

**Top bar**:
The strip across the top of the window holding the VLC menu, library toggle, folder button, media title and window controls.
_Avoid_: Title bar, menu bar, header

**Control bar**:
The strip across the bottom of the player holding playback controls, the seek bar, volume and the track, adjustments and Queue buttons.
_Avoid_: Toolbar, player bar, controller

**Layout**:
The user's arrangement of items in the Top bar and Control bar, kept separately for video and music.
_Avoid_: Profile (for this meaning), toolbar configuration

**Profile**:
A named bundle of all preferences, Theme, Accent color, scale and Layouts that the user switches between; the library, history and per-show presets are shared by all Profiles.
_Avoid_: Preset, configuration, Layout

**Settings**:
The window of all of VLC's preferences, grouped into categories, each showing basic options first and Advanced Options below.
_Avoid_: Preferences, options, simple/all settings

**Track menu**:
The popover from the Control bar's audio or subtitle button for picking video, audio and subtitle tracks and the audio output.
_Avoid_: Track selector, quick menu

**Adjustments sidebar**:
The right-hand panel with Playback, Video, Audio and Subtitles tabs for live adjustments such as delays, filters, speed and subtitle appearance.
_Avoid_: Effects dialog, adjustments and effects, settings panel

**VLC menu**:
The "…" menu at the left of the Top bar, holding the open actions, Profiles, customization, Settings and app-level items.
_Avoid_: Main menu, hamburger menu, menu bar

**Hide UI**:
A mode where both bars stay hidden and appear only when the pointer nears their edge, as in fullscreen.
_Avoid_: Minimal view, zen mode
